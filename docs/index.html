SETUP

Run it locally

Point it at your drive and open it in a browser.

zsh 
# 1. clone the repo
$ git clone https://github.com/GoldernHaze/File-Explorer.git
$ cd File-Explorer

# 2. (optional) virtual environment
$ python3 -m venv venv
$ source venv/bin/activate

# 3. install Flask
$ pip install flask

# 4. update the SSD path in app.py, then run
$ python3 app.py

→ open http://0.0.0.0 (or the address shown)

An example SSD layout

Folders like Server/ can be renamed and hidden from the UI — edit hidden_folders in app.py to match your own drive.
